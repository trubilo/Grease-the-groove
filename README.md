# GTG Pull Tracker

A mobile-first pull-up training tracker with energy calculations, grip breakdown, and progress charts.
Deployed as a single self-contained HTML file on GitHub Pages — no server, no framework, no build tools beyond Babel.

**Live URL:** https://trubilo.github.io/Grease-the-groove  
**Repo:** https://github.com/trubilo/Grease-the-groove

```
└── README.md         ← This file
```

**To make changes: edit `app.jsx`, run `./build.sh`, upload `index.html` to GitHub.**

## Build Process

```bash
# Install deps (first time only)
npm install -g @babel/core @babel/cli @babel/preset-react @babel/preset-env

# Build
chmod +x build.sh
./build.sh
```

The build does three things:
1. `npx babel app.jsx → app.compiled.js` — transpiles JSX to plain JS
2. Validates JS syntax with Node
3. `python3 bundle.py` — inlines React + compiled app into index.html

**Critical:** The bundler escapes `</script>` and `<script>` literals inside the JS bundles
to prevent HTML parser breakage. ReactDOM's minified source contains a literal `<script>` 
string in an innerHTML assignment — this was the root cause of several "won't load" bugs.

## Architecture

Single-file React app. No routing, no state management library, no CSS framework.

**State** (all in `App` component):
- `logs` — `{ "2026-05-19": { narrow:5, wide:0, neutral:0, chin:10 }, ... }`
- `weekGoal` — integer, weekly rep target
- `bodyweight` — kg, used for all energy calculations
- `draft` — unsaved edits for today's log (null = no pending changes)
- `chartScale` — "week" | "month" | "alltime"
- `editDate` — date string of entry being edited in history, or null
- `showGoal` — boolean, settings modal open
- `nav` — "today" | "stats" | "history"

**Persistence:** `localStorage` key `gtg_pull_v1`
```js
{ logs: {...}, weekGoal: 100, bodyweight: 105 }
```

**Energy calculations** (in-component, recalculate on render):
```
joulesPerRep     = bodyweight × 9.81 × 0.5   (mechanical, 0.5m ROM)
metabolicJPerRep = joulesPerRep / 0.25         (muscle ~25% efficient)
kcalPerRep       = metabolicJPerRep / 4184
```

## Key Components

### `BarChart`
Table-based (not flexbox) bar chart. Uses `<table>` for guaranteed pixel heights on Android.
Props: `data, colorFn, labelFn, valueFn, height, goal, stacked, labelEvery`
- `stacked=true` renders grip-breakdown bars (cyan/green/orange/pink segments)
- `labelEvery=5` skips labels on crowded charts (month view)
- Labels live in a separate fixed-height row above bars — critical for accurate proportions

### `GoalModal` (Settings)
Combined bodyweight + weekly goal input. Opens via ⚙ SETTINGS button on Today tab.

### `EditLogModal`
Bottom sheet for editing past log entries from History tab.
Same +1/+5/number input pattern as the inline Today logger.

### Inline Today Logger
Not a modal — lives directly on the Today page. Draft state with manual SAVE button.
`setGripVal(id, val)` merges into draft via single `setDraft` call (no double setState).

## Known Issues / History
- **Script tag escaping:** ReactDOM bundle contains `<script>` literal. Must escape in bundler.
- **Optional chaining:** Android Chrome <80 doesn't support `?.`. All removed, use explicit null checks.
- **Bar chart heights:** `flex:1` + `alignItems:flex-end` collapses on Android. Fixed with `<table>`.
- **Date/timezone:** All date functions use local time via `localDateStr()`. Never use `.toISOString()` for dates.
- **Week start:** Monday-based. `getWeekStart()` calculates correct Monday using local date parsing.
- **Storage key history:** `gtg_v1` → `gtg_v2` → `gtg_v3` → `gtg_v4` → `gtg_tracker_v1` → `gtg_pull_v1` (current)
  Do not change the storage key again. Include a migration check if schema changes.

## Deployment

1. Run `./build.sh`
2. Go to https://github.com/trubilo/Grease-the-groove
3. Upload `index.html` (overwrites existing)
4. GitHub Pages auto-deploys in ~60 seconds
5. URL: https://trubilo.github.io/Grease-the-groove

**Do not rename the file.** Users have localStorage tied to this URL.
Changing the URL = data loss for all users.

## User's Setup
- Bodyweight: ~105kg (adjustable in ⚙ SETTINGS)
- Weekly goal: 100 reps (adjustable)
- Pull-up baseline: 7 reps max
- Chin-up baseline: 10 reps max
- Dead hang baseline: 60s
- Equipment: pull-up bar (3 grip options) + chair + floor
- Uses app on Android Chrome + iPhone Safari
- Friend also uses same URL (separate localStorage = separate data)
- Data backup: ↓ SAVE button in LOG tab exports JSON to Downloads
